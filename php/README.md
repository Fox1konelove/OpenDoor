# Сайт с регистрацией и авторизацией (PHP + MySQL)

Проект переносим между компьютерами / в GitHub без ошибок:
- **index.html** — страница регистрации/входа со статусом авторизации: работает через AJAX (PHP + MySQL), сообщения и панель пользователя показываются прямо на странице;
- **index.php** — личный кабинет (показывает сообщения и авторизованного пользователя);
- **status.php** — отдаёт статус сессии (AJAX);
- **database.sql** — готовый дамп базы данных (схема + демо-пользователь).

## Требования

- XAMPP (Apache + PHP 7.4+ + MySQL/MariaDB) или любой сервер с PHP и MySQL.

## Установка (XAMPP)

1. Скопируйте папку проекта в `C:\Xampp\htdocs\` (например, `C:\Xampp\htdocs\site\`).
2. Запустите **Apache** и **MySQL** в панели XAMPP.
3. Создайте базу данных из дампа:
   ```bash
   C:\Xampp\mysql\bin\mysql.exe -uroot < database.sql
   ```
   Или через phpMyAdmin: импортируйте файл `database.sql`.
4. Откройте в браузере: `http://localhost/site/index.html`

## Установка на любом сервере (в т.ч. после переноса с GitHub)

1. Импортируйте `database.sql` в MySQL/MariaDB.
2. Проверьте доступ к БД в файле `config.php` (сервер, логин, пароль, имя базы).
3. Убедитесь, что веб-сервер умеет выполнять PHP, и откройте `index.html`.

## Структура

| Файл           | Назначение                                                |
|----------------|-----------------------------------------------------------|
| `index.html`   | Страница регистрации/входа (AJAX, статус прямо на странице) |
| `index.php`    | Личный кабинет и модальные сообщения                      |
| `status.php`   | Статус авторизации в JSON (для AJAX)                      |
| `register.php` | Обработчик регистрации (валидация + запись в БД, JSON)    |
| `login.php`    | Обработчик входа (JSON)                                   |
| `logout.php`   | Выход из аккаунта (JSON)                                  |
| `config.php`   | Настройки подключения к базе данных                       |
| `db.php`       | Подключение к БД (MySQLi)                                 |
| `database.sql` | Дамп базы данных `registerUser` (таблица `users`)         |

## Перенос на GitHub

1. Установите [Git](https://git-scm.com/).
2. В папке проекта:
   ```bash
   git init
   git add .
   git commit -m "initial"
   ```
3. Создайте репозиторий на GitHub и выполните команды, которые покажет GitHub (или загрузите файлы через веб-интерфейс).
4. На новом компьютере: склонируйте репозиторий, импортируйте `database.sql`, поправьте `config.php` при необходимости.

> ⚠️ База данных — это данные на сервере MySQL. В репозиторий передаётся файл `database.sql`, из которого базу можно полностью восстановить. Реальные учётные записи пользователей при переносе переживут дамп только если вы пересоздадите его командой:
> ```bash
> C:\Xampp\mysql\bin\mysqldump.exe -uroot --databases registerUser --result-file=database.sql --default-character-set=utf8mb4
> ```
